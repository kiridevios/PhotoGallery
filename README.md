# PhotoGallery
iOS technical assessment

## Project Setup

### Requirements
- iOS 17.0+
- Xcode

### API Configuration

1. Create an application at https://unsplash.com/developers.
2. Copy the configuration template:

   cp Configuration/Secrets.example.xcconfig Configuration/Secrets.xcconfig

3. Replace YOUR_ACCESS_KEY with your Unsplash Access Key.
4. Open PhotoGallery.xcodeproj.
5. Select an iPhone simulator and run the application.

Local API credentials are excluded from version control.
